## Назначение T-Hist

Утилита `T-Hist` предназначена для создания текстовых файлов со статистикой работы одного или нескольких FTN-мейлеров в течение заданного интервала
суток заданной даты для заданных FTN-адресов. Информацию для генерации статистики `T-Hist` получает из бинарных логов, также называемых файлами истории.

Разработка `T-Hist` была начата в 1996 году, первоначально только для получения статистики мейлера T-Mail. В дальнейшем список поддерживаемых мейлеров
и форматов бинарных логов расширился. Последняя версия `T-Hist` для DOS, OS/2 и NT (win32) – `0.30.alpha7`– была выпущена в 2003 году.
После этого процесс разработки остановился на 23 года.

В 2026 году работа над проектом была возобновлена. Выпущеные новые версии `T-Hist` и сопутствующих утилит для Linux и Windows, обладающие новыми возможностям
по сравнению со старыми версиями. Поддержка старых операционных систем удалена.

Везде далее в документе под термином `старые версии` понимается версия `0.30.alpha7` и более ранние версии утилиты,
а под термином `новые версии` – версии `1.x.x`.


## Структура распространяемого ZIP-архива с утилитами

Утилиты распространяются в виде ZIP-архива, содержащего следующие каталоги:
- `linux` – исполняемые файлы Linux для архитектур x86_64, i686 и arm64;
- `linux-static` – исполняемые файлы Linux для архитектур x86_64, i686 и arm64, скомпилированные со статическими библиотеками;
- `windows` – исполняемые файлы для Windows 64-bit и 32-bit;
- `doc` – документация;
- `binkd_patch` – патчи для Binkd, добавляющие поддержку бинарных логов формата `T-Hist`.

Исполняемые файлы Linux, скомпилированные со статическими библиотеками, сжаты упаковщиком [UPX 4.2.4](https://upx.github.io) для уменьшения размера.

Каталог с документацией содержит:
- файл [T-HIST-ru.md](./doc/T-HIST-ru.md) с описанием `T-Hist` и сопутствующих утилит;
- пример конфигурационного файла [t-hist.ctl](./doc/t-hist.ctl) с подробным описанием параметров;
- файлы [FORMATS-ru.md](./doc/FORMATS-ru.md) и [FORMATS.md](./doc/FORMATS.md) с описанием форматов бинарных логов, включая несколько версий собственного
формата `T-Hist` (на русском и английском языках);
- старый файл документации [t-hist-old.txt](./doc/t-hist-old.txt) от версии `0.30.alpha7`, приведённый в справочных целях.

Кодировка текстовых файлов UTF-8.


## Виды генерируемой статистики

Результатом работы `T-Hist` являются три текстовых файла:
- файл с графиком и гистограммами загрузки FTN-системы для одного или нескольких одновременно работающих мейлеров;
- файл со статистикой линков, где в таблице для каждого FTN-адреса, включаемого в статистику, приведёно число сессий,
их суммарная длительность и суммарный трафик в течение заданного интервала времени;
- файл со статистикой сессий, где в таблице для каждой сессии, выполненной в течение заданного интервала времени,
приведена её длительность и значения переданного/принятого трафика.

В конце каждого из создаваемых файлов выводится суммарная информация о числе и продолжительности всех входящих и
исходящих сессий, суммарное число сессий и их продолжительность, объём полученного и переданного трафика и средний CPS,
характеризующий скорость передачи/приёма данных (CPS – "chars per second", или, что то же самое, "bytes per second").
Если мейлер поддерживает отметку сессий, защищённых паролем, то в суммарной информации также выводятся значения для
парольных и непарольных сессий.

Все файлы имеют кодировку UTF-8. Если созданную статистику необходимо разместить в русскоязычной эхоконференции или нетмейле, преобразуйте файлы
в кодировку CP866:
```shell
iconv -f UTF-8 -t CP866 in.txt -o out.txt
```

## Режим широкого экрана

Старые версии `T-Hist` и сопутствующих утилит содавали файлы статистики со строками, длина которых не превышала
80 символов. В новых версиях появился режим широкого экрана, который включен по умолчанию. В этом режиме
справа от графика загрузки и от таблиц со статистикой может выводиться дополнительная текстовая информация, которая
есть в бинарных логах некоторых мейлеров, или описания адресов, которые можно задавать в параметрах `Addr`

Не все мейлеры содержат в бинарных логах дополнительную информацию, которая может быть выведена в виде текста. Например,
в бинарных логах мейлера Binkd такой информации нет. Если вы не задаёте описания к адресам в параметрах `Addr`,
то создаваемая для Binkd статистика будет иметь ширину не более 80 символов даже в режиме широкого экрана.

Но некоторые из поддерживаемых мейлеров содержат в бинарных логах текстовую информацию о FTN-системах, с которыми проводились сессии, или информацию
о протоколе соединения, или диагностические сообщения. К таким мейлерам относятся: qico 0.60.2+, Internet Rex, FrontDoor, Bink/+, FhMail, BinkleyTerm-XE,
KittenMail, The Brake!, некоторые мейлеры с логами в формате T-Mail версии 2603 и новее, и мейлеры, использующими бинарные логи формата `T-Hist`.
Для этих мейлеров текстовая информация будет выводиться в режиме широкого экрана.

Для управления режимом широкого экрана используется параметр `WideScreen` в конфигурационном файле или опция командной строки `-w`.


## Конфигурационный файл. Параметры. Опции командной строки

Работа `T-Hist` и сопутствующих утилит управляется параметрами, значения которых могут быть заданы в конфигурационном файле. Также часть параметров
может быть задана с помощью опций командной строки. По умолчанию, конфигурационный файл имеет имя `t-hist.ctl` и располагается в текущем каталоге.
Для задания другого конфигурационного файла или указания работать без файла конфигуации используется опция командной строки `-c`.

Имена и значения всех параметров регистронезависимые за исключением имён файлов в Linux. Комментарии могут начинаться с символов `#` и `;`.
Для использования русского текста в комментариях и в параметрах, имеющих текстовые значения, используйте кодировку UTF-8.

Если какой-либо из параметров задан и в конфигурационном файле, и с помощью опции командной строки, то будет использоваться значение из командной строки.

Описания всех параметров и всех опций командной строки приведены в примере конфигурационного файла [t-hist.ctl](./doc/t-hist.ctl) и в файле документации
[T-HIST-ru.md](./doc/T-HIST-ru.md), которые находятся в каталоге [doc](./doc).


## Собственный формат бинарных логов. Конвертер форматов

Недостатком форматов бинарных логов всех мейлеров, поддерживаемых старыми версиями `T-Hist`, является использование
32-битных величин для записи информации о количестве отправленных и полученных байт. В таких бинарных логах невозможно
корректно сохранить информацию о трафике, если во время сессии было отправлено или получено более 4 гигабайт.

Форматы бинарных логов мейлеров разрабатывались в эпоху dial-up, когда передать более 4 гигабайт за одну сессию было
практически нереально. Но в эпоху Fido-over-IP и высокоскоростных сетей сессия с трафиком более 4 гигабайт – обычное
явление, особенно на крупных раздающих хабах.

В новых версиях `T-Hist` и сопутствующих утилит реализована поддержка нескольких версий собственного формата бинарных
логов с 64-битными значениями трафика и отметками времени. Разработчикам FTN-мейлеров предлагается использовать бинарные
логи собственного формата `T-Hist` в своих программных продуктах. Помимо корректного сохранения данных о сессиях с большими
объёмами трафика, формат позволяет сохранять текстовые строки с информацией о FTN-системах и/или с диагностическими
сообщениями, которые могут быть выведены в статистике в режиме широкого экрана. Также формат `T-Hist` позволяет записывать
в бинарный лог отметку `Listed` для сессий, FTN-адреса которых присутствуют в нодлистах, указанных в конфигурации мейлера.
Подробно все версии собственного формата бинарных логов `T-Hist` рассмотрены в файле
[FORMATS-ru.md](./doc/FORMATS-ru.md), находящемся в каталоге [doc](./doc).

На момент выхода версии `T-Hist` `1.8.2`, бинарные логи формата `T-Hist` использует мейлер
[qico 0.60.2](https://github.com/glasslike/qico) by Alexey Matrosov (2:203/910).

Существует возможность добавить поддержку бинарного лога формата `T-Hist` к мейлеру Binkd. При этом родной бинарный лог
Binkd затронут не будет: новый бинарный лог будет записываться "параллельно" с родным бинарным логом. Для добавления к
Binkd поддержки бинарного лога формата `T-Hist` используйте один из патчей, находящихся в каталоге
[binkd_patch](./binkd_patch). Подробнее об этих патчах и алгоритме их применения читайте в файле
[BINKD-PATCH-ru.md](./binkd_patch/BINKD-PATCH-ru.md).

Для удобства работы с разными форматами бинарных логов создан конвертер `HistConv`. Утилита `HistConv` позволяет для
заданного бинарного лога создать такой же лог в другом формате. В качестве исходного может быть указан файл бинарного
лога любого мейлера, поддерживаемого `T-Hist`. В качестве целевого может быть выбран один из следующих форматов:
  - собственный формат `T-Hist` любой из версий;
  - формат T-Mail версий 2603 и новее (новый формат T-Mail);
  - формат T-Mail до версии 2603 (старый формат T-Mail);
  - формат Binkd (старый формат T-Mail с инвертированной отметкой входящих/исходящих сессий).

Подробнее об утилите `HistConv` читайте в разделе
[Конвертер форматов бинарных логов HistConv](./doc/T-HIST-ru.md#конвертер-форматов-бинарных-логов-histconv)
файла документации [T-HIST-ru.md](./doc/T-HIST-ru.md).


## Утилита LnkStat для создания многодневной статистики линков

В состав пакета `T-Hist` входит утилита `LnkStat`, предназначенная для создания многодневной статистики линков.
В отличие от `T-Hist`, который создаёт статистику для интервалов времени, не превышающих 24 часа, `LnkStat` создаёт
статистику для диапазона дат, заданного опциями командной строки (по умолчанию: для диапазона дат всех сессий с
заданными адресами, прочитанных из обрабатываемых бинарных логов – от даты самой старой сессии до даты самой новой
сессии включительно).

Результатом работы `LnkStat` является таблица, аналогичная таблице статистики линков, формируемой `T-Hist`.
По умолчанию, `LnkStat` выводит статистику в `stdout`, но можно с помощью опции командной строки `-o` указать
имя файла для вывода статистики.

Так же, как и `T-Hist`, утилита `LnkStat` может работать в режиме широкого экрана, выводя справа от строк таблицы
текстовую информацию из бинарных логов или описания адресов из параметров `Addr`.

## Дампер бинарных логов DmpHist

В состав пакета `T-Hist` входит утилита `DmpHist`, которая для каждого обрабатываемого бинарного лога выводит
в `stdout` все его записи в виде таблицы, содержащей:
- FTN-адрес, с которым проводилась сессия (в случае неудачного хэндшейка: `0:0/0.0`);
- дату и время начала сессии;
- длительность сессии в секундах;
- значения полученного и отправленного трафика;
- набор битов статуса сессии.

Так же, как `T-Hist` и `LnkStat`, утилита `DmpHist` может работать в режиме широкого экрана, выводя справа от строк
таблицы текстовую информацию из бинарных логов, если она есть.
